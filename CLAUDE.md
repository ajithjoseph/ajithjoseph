# Profile README

This repo holds my GitHub profile page. `README.md` is the page itself.

## Style
- Text only. Don't use outside image services (shields.io, skillicons.dev, stats cards). They load unreliably. If an image is really needed, save the file in `assets/` and link to it from there, like the ThyWord QR codes.
- Use plain markdown tables and short sentences. Write in first person, in a natural voice.
- Keep the tone modest. Describe the PerfAgents acquisition in one short line, with no numbers.
- Describe enterprise work by industry rather than by company.
- Link only to LinkedIn, Credly, GitHub repos, shadowtel.com, evalstack.dev, thywordapp.com, perfagents.com, the app store pages and the Amazon page for my book.

## Facts to keep consistent
- Titles: PerfAgents, Founder · Principal Engineer. ThyWord and Shepherd, Co-Founder · Principal Engineer.
- ThyWord: launched February 2026, 15K+ downloads.
- ShadowTel: in development. Open source GitHub Action that blocks PRs when AI-written code breaks schema, API or architecture rules.
- EvalStack: early release (v0.0.1).
- Shepherd: early B2B product for churches.
- Retrieval stack: PostgreSQL with pgvector. Don't list Pinecone.
- Only list tools in the stack that I have actually used. Don't add tools for products that aren't built yet.

## Workflow
- Make changes on a branch, open a PR, and squash-merge it with a short first-person commit message.
- Before changing a fact, check it against my resume and repos. Ask me if they disagree.
